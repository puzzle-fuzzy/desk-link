# macOS 功能对齐：第 3 项

日期：2026-10-23。承接第 1、2 项，本轮补齐 Mac 控制现有 Windows 主机的输入和会话功能；未修改 Windows 发布程序或升级线协议。

## 使用方式

- 点击远端画面后，可使用本机中文输入法。候选拼写与候选确认在本机处理，只提交最终文字；支持中文、emoji 和多行。也可用工具栏“发送文字”，单次最多 4096 字节 UTF-8。
- 默认 Command 映射 Ctrl，Option 映射 Alt；“快捷键映射”可切换 Command 映射 Windows 键。Ctrl、Shift 等支持独立按下/松开，连续 Option+Tab 保留 Alt 的持有状态。组合键菜单提供 Windows 键、Alt+Tab、任务管理器。
- “屏幕切换”展示远端真实上报的显示器及分辨率。目标屏确认及其新画面呈现前暂停远端输入；失败/超时可重试，旧输入与输入法回调不会落到新屏幕。
- “画质选择”提供自动、流畅、均衡、清晰，自动模式同时展示实际应用档位。等待远端确认期间单独展示请求状态。
- “剪贴板”提供本机发送到远端、远端取回本机、发送后粘贴，限纯文本 48 KiB UTF-8。默认自动映射模式下 Command+V，或 Control+V，会发送本机文本并等待远端写入完成后才发粘贴键；原始模式 Command+V 保留 Windows+V 含义。
- 本机剪贴板仅在上述用户操作后读取，匹配的取回响应才写入；没有后台轮询或自动同步。失焦、切屏、切模式及断线会取消等待中的智能粘贴。图片/文件不在本项范围。

## 实现与边界

Rust FFI 新增 6 个窄接口、SESSION/CLIPBOARD 有界 JSON 事件；两份 C 头文件与 ABI 校验同步。命令绑定连接 epoch 和 stream，屏幕复用 stream ID 也会淘汰旧输入。剪贴板使用单调 request ID、操作类型、流及回调代际隔离，并设置有界超时；不记录文本正文。

AppKit 输入采用 NSTextInputClient，并为每次输入上下文创建独立代理，以丢弃失焦/重连后的迟到输入法回调。共享 Bridge 将提交文本作为一次有序批次发送，快捷键双边沿发送，操作后有释放保护。Mac 被控端也补充持有修饰键的 CGEvent 标记合成，但 Mac 主机多屏/剪贴板服务仍属于后续被控端建设。

现有协议未直接把显示器 ID 与跨 lane 视频配置关联。选屏通过真实显示器确认、配置版本和确认后的解码帧进行防护；覆盖超时重试同目标、返回原屏及拒绝已放弃屏幕的中间配置。真实多屏设备仍需实机验收。Windows 安全界面 Ctrl+Alt+Delete 未作为可用组合键展示。

## 验证结果

以下门禁均通过：

```sh
cargo clippy -p desklink-ffi --all-targets -- -D warnings
./scripts/verify-macos-runtime.sh
./scripts/verify-ios.sh
```

- Rust 65 项：状态机 15、FFI 48、端到端恢复 2。FFI 包含本地真实 QUIC/Noise 加密链路的屏幕、画质、中文/emoji/换行、剪贴板收发与过期响应测试。
- Apple 共享核心 48 项，其中本项新增 15 项会话功能回归。
- macOS 81 项，其中本项新增 25 项输入法、快捷键、剪贴板和被控端修饰键回归。
- iOS 20 项单元测试、2 项 UI 测试；未签名设备构建与模拟器测试通过。
- 合计 216 项，不重复计算脚本中再次执行的共享测试。

独立 DEBUG 原生验收程序检查了屏幕选择及新画面、画质确认、双向剪贴板与智能粘贴反馈、中文/emoji/多行文本编辑提交、快捷键映射与组合键菜单。验收程序使用内存剪贴板及合成远端，不读取系统剪贴板或钥匙串。正式 Release 二进制不含该入口。

正式安装版也已启动并完成真实 Windows 连接：原有记录可用，收到实时画面和远端光标、2560×1440 单屏列表；切换流畅画质并获得远端确认，随后恢复自动画质。已断开验证连接，应用保持在连接页面，原记录及上次连接时间正常。

真实远端出现同时操作迹象后，结束了临时输入验证。中文候选、持续快捷键和双向剪贴板未记为 Windows 实机验收通过；该远端只上报一块屏幕，真实多屏切换也待验证。以上自动测试和隔离验收不替代这些实机结果。
