# macOS 对齐第 5 项：被控端设备 ID 与访问密码

本阶段在现有 Mac 被控端上补齐与 Windows 相同的设备目录入口。设备身份、已批准设备和原有控制端连接记录沿用原存储，不重建或删除。

## 行为

- 设备 ID：以本机已有的 16 字节 host device ID 前 8 字节按大端解析，映射为 12 位设备号，并以每 3 位一组显示。此算法与 Windows 一致；换密码不换设备 ID。
- 临时密码：通过系统安全随机源生成 8 位访问码，字符集与 Windows 相同。中继确认注册成功后才显示、允许复制，默认隐藏；10 分钟后不再接受新连接。刷新、关闭共享或切换方式会撤回旧邀请。已建立的会话可继续。
- 固定密码：8 位字母或数字，忽略大小写、空格和连字符，不允许易混字符 0、1、I、O。通过两个安全输入框确认，保存在独立的 macOS 钥匙串条目中；不在页面回显。写入或删除失败会保留原凭据及共享状态。
- 访问模式：同一设备 ID 当前注册临时密码或固定密码中的一种，符合 Windows 的单模式语义。固定模式的邀请只在本次共享连接存活期间有效；每次重新开启均产生新的会话和邀请。
- iPhone 二维码：复用当前临时密码对应的已签名邀请，不另外启动一套被控端。
- 批准与信任：密码只用于取得签名邀请，仍需通过 Noise 身份校验。陌生设备首次连接必须在 Mac 上批准；已批准设备只有 ID 与公钥完全匹配才可自动重连。同 ID 换公钥仍需本机批准。
- 停止与轮换：即时隐藏临时密码、二维码和待批准请求，拒绝迟到回调；等待旧注册结束并关闭旧 QUIC 后才注册新会话。网络调用和销毁在后台执行，界面保持响应。注册中取消受底层连接及加入超时约束。
- 权限：读取设备 ID、设置固定密码无需开启屏幕录制；实际开启共享需要屏幕录制和辅助功能均已授权。权限撤销会停止共享并释放输入。

## 代码入口

- `apps/macos/Sources/DeskLinkApp/Bridge/HostAccessCredentials.swift`：设备号、密码规则和钥匙串存储。
- `apps/macos/Sources/DeskLinkApp/Bridge/HostBridge.swift`：共享生命周期、模式切换、回调隔离和已批准设备恢复。
- `apps/macos/Sources/DeskLinkApp/Views/HostAccessPanel.swift`：共享控制和安全密码设置界面。
- `crates/desklink-ffi/src/host_directory.rs`：签名邀请、目录注册与有效期。
- `crates/desklink-ffi/src/host_worker.rs`：真实中继加入、批准、连接与关闭。
- `crates/desklink-transport/src/quic.rs`：停止时等待 QUIC 关闭排空，避免中继保留旧目录记录。

## 验证范围

测试使用内存钥匙串和隔离的本地 QUIC 中继，覆盖临时/固定密码查找、错误密码、首次批准、加密输入、轮换、停止、重连身份约束，以及临时密码过期前后的会话行为。原有控制端音频、文件、输入与显示能力继续回归。

原生界面在独立的 DEBUG 应用中验证，使用内存身份、内存密码和模拟注册，不读取生产钥匙串、不捕获桌面、不注入输入、不连接真实中继。验证开启共享后才显示隐藏密码、切换固定模式后撤回临时码和二维码、安全输入框与取消、停止共享。Release 不包含这些验收入口。

最终构建、安装、哈希、签名、测试数量和本机权限状态记录在 `dist/macos/installation-report.json`。本机真实屏幕录制与辅助功能授权以及跨设备画面/输入验收，必须以安装后实际窗口和真实操作结果为准，不能由隔离测试替代。
