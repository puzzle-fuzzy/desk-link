# Host media producer contracts

`host-media-cursor-producer.json` and `host-media-listener-producer.json` are
generated by compiling and running the
production `DiagnosticEvent::HostMedia` encoder at the recorded complete commit.
Their `line` values retain the encoder's original JSONL, including the real
`SystemTime` timestamp and final LF. The generator validates the four typed input
tuples without parsing/reformatting those output strings. Tests should use each
line's timestamp as their validation clock.

From the repository root, run:

```powershell
python server/diagnostics/scripts/generate-host-media-contract.py
```

The default producer is `a599246535b73f57e0425cbbfd18c7156e050bba`; an intentional
producer update can use `--producer-commit`. Scratch sources, Cargo files and
build output stay in
`E:\desk-link\.worktrees\dl2-targets\dl2-services\cursor-contract`. The script
refuses to overwrite an unmarked nonempty scratch directory and never deletes
it. `--scratch` and `--output` can select explicit destinations.

For the independent direct-listener contract, run:

```powershell
python server/diagnostics/scripts/generate-host-media-contract.py --event direct-listener
```

This mode defaults to producer `6dbe53d64c60bbdd50af4b592ebef7471b800fcc`, scratch
`E:\desk-link\.worktrees\dl2-targets\dl2-services\listener-contract`, and output
`host-media-listener-producer.json`. It does not rewrite the cursor fixture.
The no-argument mode remains equivalent to `--event cursor`, using the original
cursor producer, scratch and output defaults. `--producer-commit`, `--scratch`
and `--output` override the selected mode's defaults explicitly.

The isolated crate `include!`s the complete original `diagnostics.rs` and
`runtime/media_diagnostics.rs`, and the exact original derive/enum/impl fragment
for `CursorDisableReason` from `runtime/cursor_send.rs`. Only unrelated storage
lookups, `H264Profile`, `HostLifecycleEvent`, and the unused observer JSON fallback
are stubbed. The storage/fallback functions panic if called. The actual host
media match arms, format strings, clock and JSONL wrapper are untouched.
Listener mode reexports the real `DirectListenerStopReason` defined by the full
included `media_diagnostics.rs`; it does not substitute a reason enum.
This fixture proves encoder/consumer compatibility for constructed typed events;
it does not claim actual cursor delivery, listener retirement or hardware execution.

Only `serde` with `derive` and `thiserror` are direct Cargo dependencies. Their
exact versions, transitive dependency closure and checksums come from the pinned
producer's `Cargo.lock`. Compilation runs `scripts/run-windows-cargo.py run
--quiet --locked --offline --manifest-path <scratch>/Cargo.toml` using that
producer's repository toolchain and an E: `CARGO_TARGET_DIR`. No root lockfile or
desktop sources are changed and no dependencies/toolchains are downloaded.

The fixture records the actual `rustc -Vv` output plus Git blob IDs and SHA-256
hashes for all three producer files, the workspace manifest, lock and toolchain.
Cases are `disabled` `(7,2,1,true)`, `enabled` `(8,5,2,false)`, `max_safe` with all
three counters/IDs equal to `9007199254740991`, and `u64_overflow` with all three
equal to `18446744073709551615`. Both boundary cases use `disabled=true`.
The last case preserves the Rust integer text exactly and must be rejected by
the server's JavaScript-safe numeric contract. No identity, key, credentials,
cursor pixels or input data is included.

Listener cases are `retired_true` `(stream_id=7, retired_active=true)`,
`retired_false` `(8,false)`, `max_safe` `(9007199254740991,true)`, and
`u64_overflow` `(18446744073709551615,true)`. Their actual producer event is
`host_direct_listener_stopped`, level `warning`, reason `listener_closed`.
The overflow stream ID must be rejected by the server's safe-number contract.
